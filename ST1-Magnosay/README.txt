ST1 Portfolio - game-style portfolio website (plain HTML/CSS/JS, no install, no server)

HOW TO OPEN
  Unzip this folder and double-click index.html.
  Drive with W A S D or the arrow keys. Park in a bay and press ENTER to open it.
  On a phone, use the on-screen buttons. The "Stops" button jumps to any stop.

WHAT TO EDIT
  data.js     all the text: your info, each seminar's title/date/speaker,
              the takeaway, links, and which image files to use.
  assets/     the screenshots and certificates. Paths in data.js point here.
              A missing file shows a placeholder that names the file to add.

ADD A SEMINAR
  Copy one block in the "seminars" list in data.js, put its files in a new
  assets/<folder>/, and the road grows by one stop automatically.

FILES
  index.html  page shell
  style.css   look and layout
  game.js     the driving game and the panels
  data.js     your content
  assets/     images and PDFs
